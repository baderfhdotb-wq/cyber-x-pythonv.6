# CYBERNEX V6 — SCROLL CINEMA

Two deliberately different visual worlds:
- Cybersecurity: red/black with green protection states, an interactive scroll-animated lock and radar.
- Python: blue/yellow with a 3D-like code editor and code execution sequence.

Each world has its own 265vh scroll sequence with a sticky full-screen stage, located between lessons (not stuck as a rotating object in the background). Existing lessons, cyber simulations, Python lab, teacher notes, cinematic gateways, and presentation mode remain.

## Deploy
Upload all files from this directory to the root of your GitHub repository. Vercel: Framework Preset Other; no build command; root directory ./ .

Uses CDN libraries Three.js and GSAP; requires internet. Animations adapt to prefers-reduced-motion. This release has not been browser-tested.

To add your future reference images, share them and the visual scenes can be revised.
